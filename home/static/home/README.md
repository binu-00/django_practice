# 🎬 CineMood AI

### Movie Recommendation System

CineMood AI is a Python-based movie recommendation project that helps users discover movies based on their mood, preferences, and favourite genres.

## 🚀 Features
- Mood-based movie recommendations
- Genre-based selection
- User-friendly interface
- Movie recommendation scoring system

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
